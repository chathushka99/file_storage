# file_storage
This is a simple file storage API to save small video files in an H2 database.

## Run locally

1. `chmod +x start.sh` (first time only)
2. `./start.sh`

Windows:
1. `cd filestorage`
2. `mvnw.cmd spring-boot:run`

## Test

1. `cd filestorage`
2. `./mvnw test` (Windows: `mvnw.cmd test`)
